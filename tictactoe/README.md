# Tic Tac Toe

A simple text-based Tic Tac Toe game.

## How to Play

1. Run the game.
2. Enter a number from 1 to 9 to place your mark on the board.
3. The first player to get three in a row wins!

## Features

* Simple text-based interface
* Two-player game
* Win condition checking
